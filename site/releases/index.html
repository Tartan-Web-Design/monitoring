MigrateWP 1.1

Latest 10 September 2021

The current release. Adds the standalone rollback command, lets you attach a comment to a migration or rollback, and removes the need for root access on the remote server — any server you can SSH into will do.

Download 1.1

MigrateWP 1.0

Initial release 31 August 2021

The first public release: push, pull and report, driven by rsync and WP-CLI over SSH, with backups taken before every migration.
